Petunjuk Penggunaan Media

Selamat datang! Media interaktif ini dirancang untuk membantumu memahami konsep Grafik Fungsi Kuadrat secara visual.

  1. Mengubah Nilai Parameter: Geser slider atau ketik angka pada kotak a, b, dan c untuk melihat perubahan grafik secara langsung.
  2. Titik-Titik Penting:
    • ● Titik Merah (P) = Titik Puncak / Titik Balik Parabola.
    • ● Titik Oranye = Titik Potong Parabola dengan Sumbu-Y.
    • ● Titik Hijau = Titik Potong Parabola dengan Sumbu-X (Akar-akar).
  3. Mode Tantangan (Game): Klik tombol "Mode Tantangan: OFF" untuk mengaktifkan permainan tembak target. Target akan otomatis diperbarui setiap kali kamu berhasil mengenainya!
  4. Pengerjaan LKPD: Buka tab "LKPD Interaktif" untuk menyelesaikan lembar kerja eksplorasi. Hasil pengerjaan dapat dicetak atau disimpan sebagai PDF.

Lembar Kerja Peserta Didik (LKPD)

Isi identitas dan kerjakan eksplorasi berikut dengan menggeser slider pada grafik!

Kegiatan 1: Pengaruh Nilai a terhadap Grafik

Atur b = 0 dan c = 0. Ubah nilai a menjadi positif (a > 0), lalu ubah menjadi negatif (a < 0).

Kegiatan 2: Pengaruh Nilai c terhadap Titik Potong Sumbu-Y

Atur a = 1 dan b = 0. Ubah nilai c (misal c = -3, c = 0, c = 4).

Kegiatan 3: Hubungan Diskriminan (D) dengan Titik Potong Sumbu-X

Coba buat fungsi kuadrat dengan syarat:

  • a) D > 0 (Contoh: a=1, b=0, c=-4)
  • b) D = 0 (Contoh: a=1, b=-2, c=1)
  • c) D < 0 (Contoh: a=1, b=0, c=4)
