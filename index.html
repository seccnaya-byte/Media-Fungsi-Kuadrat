Petunjuk Penggunaan Media Interaktif

Selamat datang! Media interaktif ini dirancang untuk membantumu memahami konsep Grafik Fungsi Kuadrat secara visual dan konseptual.


  1. Mengubah Nilai Parameter: Geser slider atau ketik angka pada kotak a, b, dan c untuk melihat perubahan grafik secara real-time.
  2. Titik-Titik Penting:
    • ● Titik Merah (P) = Titik Puncak / Titik Balik Parabola.
    • ● Titik Orange = Titik Potong Parabola dengan Sumbu-Y.
    • ● Titik Hijau = Titik Potong Parabola dengan Sumbu-X (Akar-akar).
  3. Mode Tantangan (Game): Klik tombol "Mode Tantangan: OFF" untuk mengaktifkan permainan tembak target. Sesuaikan nilai a, b, c agar kurva mengenai sasaran bintang merah. Setiap target berhasil akan otomatis memberi +100 Poin.
  4. Simulasi Kontekstual Bola Basket: Buka tab "Simulasi Bola Basket" untuk melihat penerapan parabola dalam lemparan bola ke ring basket secara visual dan ter-animasi.
  5. Pengerjaan LKPD Digital: Buka tab "LKPD Digital" untuk menyelesaikan lembar kerja eksplorasi. Hasil skor game akan terisi otomatis, lalu unduh jawaban dalam format PDF.

🏀 Visualisasi Kontekstual: Lemparan Bola Basket

Skenario: Sebuah lemparan bola basket mengikuti persamaan lintasan y = -x² + 6x + 2.


📝 Analisis Mandiri Lintasan Bola Basket:

Amatilah simulasi grafik di atas, lalu tentukan karakteristik matematis lintasannya berikut:

1. Berapakah tinggi awal bola basket saat pelempar pertama kali melepaskan bola (x = 0)?
2. Hitunglah jarak horizontal (x_v = -b / 2a) saat bola berada di titik tertinggi!
3. Berapakah tinggi maksimum (y_v) yang dicapai oleh bola basket tersebut?
4. Mengapa parabola lintasan bola tersebut terbuka ke bawah?

🏆 Skor Game Tembak Target (Otomatis)

Skor terisi otomatis dari hasil permainan di canvas (Read-Only):

Kegiatan 1: Pengaruh Nilai a (Keterbukaan & Kelebaran)

Atur b = 0 dan c = 0. Ubah-ubah nilai a dari positif ke negatif, serta dari nilai kecil ke besar.

1. Bagaimana pengaruh tanda nilai a (positif/negatif) terhadap bentuk parabola?
2. Bagaimana pengaruh nilai mutlak |a| terhadap tingkat kelebaran kurva parabola?

Kegiatan 2: Pengaruh Nilai b (Sumbu Simetri & Titik Puncak)

Atur a = 1 dan c = 0. Ubah nilai b dari negatif, nol, hingga positif.

1. Saat a > 0, ke arah manakah sumbu simetri dan titik puncak bergeser jika nilai b bernilai positif (b > 0)?
2. Saat a > 0, ke arah manakah sumbu simetri dan titik puncak bergeser jika nilai b bernilai negatif (b < 0)?

Kegiatan 3: Pengaruh Nilai c (Titik Potong Sumbu-Y)

Atur a = 1 dan b = 0. Ubah-ubah nilai c.

Apa hubungan antara nilai c dengan koordinat titik potong kurva parabola pada Sumbu-Y?

Kegiatan 4: Analisis Diskriminan (D = b² - 4ac)

Eksplorasi hubungan nilai Diskriminan (D) dengan banyaknya titik potong Sumbu-X.

Jelaskan kondisi grafik saat D > 0, D = 0, dan D < 0!
